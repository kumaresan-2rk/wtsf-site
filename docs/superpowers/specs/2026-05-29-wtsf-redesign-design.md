# WTSF Website Redesign

## Overview
Complete static HTML rebuild of the World Traditional Silambattam Federation website. Replace the existing HTTrack-mirrored WordPress site with a modern mobile-first responsive design. JSON-driven content, zero backend, deployable to any static host.

## Pages
All 7 existing pages kept:
- `index.html` — Home
- `about.html` — About Us
- `blog.html` — Blog/news posts (replaces the old gallery concept with separate blog)
- `instructors.html` — Instructor listing with filters + generated individual profiles
- `events.html` — Events
- `classes.html` — Classes (basic layout with placeholder content; actual class schedule/details to be filled by user later)
- `contacts.html` — Contact Us

## Architecture

### File Structure
```
├── index.html
├── about.html
├── blog.html
├── instructors.html
├── instructors/{id}.html          (generated by generate.js)
├── events.html
├── classes.html
├── contacts.html
├── css/
│   └── style.css                  (single CSS file, mobile-first, custom properties)
├── js/
│   ├── main.js                    (navigation, hamburger menu, common)
│   ├── instructors.js             (filter logic, loads data/instructors.json)
│   └── blog.js                    (blog post rendering, loads data/blog.json)
├── data/
│   ├── instructors.json           (all instructor data)
│   └── blog.json                  (all blog posts)
├── assets/
│   ├── images/                    (logos, site-wide images)
│   ├── instructors/               (instructor photos)
│   └── blog/                      (blog post images)
└── generate.js                    (local script: reads JSON → generates instructor HTML files)
```

### Key Principles
- Shared single CSS file across all pages (no WordPress boilerplate duplication)
- Header and footer markup repeated per page (static site, no build step needed for the framework itself)
- JSON files are the single source of truth for instructors and blog content
- generate.js is a local-only convenience script for generating instructor profile pages

## Design System

### Color Palette
- Background: `#0f0f0f`
- Card/surface: `#1a1a1a`
- Border/divider: `#2a2a2a`
- Primary accent: `#e8a84c` (gold/amber)
- Text primary: `#f0f0f0`
- Text secondary: `#a0a0a0`
- Input/field background: `#252525`

### Typography
- System font stack (sans-serif)
- Base size: 16px
- Line-height: 1.6
- Headings: bold weight, clear hierarchy (h1–h4)
- No web font dependencies (avoids external requests)

### Breakpoints (Mobile-First)
- Base: `< 640px` — single column, hamburger menu
- Tablet: `640px–1024px` — 2 columns, visible inline nav
- Desktop: `> 1024px` — 3 columns, full horizontal nav

### Navigation
- Desktop: horizontal bar with inline links, active state with accent underline
- Mobile: slide-in hamburger menu from left, smooth CSS transition
- Touch targets: minimum 44×44px
- Nav items: Home | About | Blog | Instructors | Events | Classes | Contact

## Instructor System

### Data Model (data/instructors.json)
```json
[{
  "id": "cbe-001",
  "fullId": "WTSF-D-CBE-2026-001",
  "name": "Guru Kumaresan",
  "state": "Tamil Nadu",
  "district": "Coimbatore",
  "photo": "assets/instructors/cbe-001.jpg",
  "specialization": "Silambattam",
  "experience": 25,
  "bio": "Full bio text here...",
  "social": { "instagram": "...", "youtube": "..." }
}]
```

### instructors.html — Filter & Listing
- Two cascading dropdowns: State → District (second populates based on State selection)
- Search input for name/specialization text search
- Responsive card grid (3 cols desktop, 2 tablet, 1 mobile)
- Each card: photo, name, district, specialization
- Click card → navigates to `instructors/{id}.html`

### Individual Profile Page (instructors/{id}.html)
- Generated by `generate.js` from `data/instructors.json`
- Full-size photo, name, full ID, district/state, specialization
- Bio section
- Experience indicator
- Social media links (Instagram, YouTube)
- Back link to `instructors.html`

### generate.js Script
- Reads `data/instructors.json`
- Validates required fields (id, name, photo, district)
- Generates `instructors/{id}.html` from an inline template string
- Optionally generates `instructors/index.html` (redirect)
- CLI: `node generate.js`

## Blog System

### Data Model (data/blog.json)
```json
[{
  "id": "post-001",
  "title": "Annual Tournament 2026",
  "date": "2026-05-15",
  "coverImage": "assets/blog/tournament-2026-cover.jpg",
  "images": ["img1.jpg", "img2.jpg"],
  "content": "Full article content in markdown or plain text...",
  "excerpt": "Short summary for the listing page",
  "category": "Events"
}]
```

### blog.html
- Blog grid: cover image, title, date, excerpt
- Category filter buttons
- Click a post → opens detailed post view in a lightbox/modal overlay on the same page (JS reads blog.json and renders full post content)
- Pagination if >12 posts
- Each post shows full content, image gallery within the post

## Mobile Responsiveness
- Hamburger menu: slide-in from left with overlay, CSS-based (no JS framework)
- Cards stack to single column on mobile
- Images: max-width 100%, responsive
- Forms/inputs: full-width, touch-friendly
- No horizontal scroll
- No text requires zooming to read

## Performance
- Single CSS file, minimal JS files
- No external font dependencies
- Images optimized (compressed, appropriate sizes)
- No jQuery or heavy libraries
- Vanilla JS only

## Hosting
- Static host: GitHub Pages, Netlify, Cloudflare Pages
- No server-side processing required
- No database
- Auto-deploy on git push

## Content Workflow
1. Edit `data/instructors.json` or `data/blog.json` manually
2. Run `node generate.js` (for instructors)
3. Commit and push to deploy
